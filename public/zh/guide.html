使用指南

跟着思路写，不必停下来找工具。

ByeByeBoard 是一个以连续书写为核心的浏览器白板。直接打字创建便签，用键盘把内容写成层级，也可以随时跳到画布的其他位置继续讨论。

打开白板 →

四步开始一块白板

1. 写下第一个想法

打开白板后直接打字，文字会成为自由光标位置的一条便签。按 Esc 结束编辑。

2. 继续或展开

按 Enter 写同级下一条；按 Tab 在右侧创建自动连线的子级；按 Shift + Tab 回到上一级继续写。

3. 在想法之间移动

用方向键选中该方向最近的便签。选中后可按 Shift + 方向键挪动它，也可以用鼠标拖动便签、平移或缩放画布。

4. 带走结果

下载 PNG 图片用于演示或发送消息；也可以下载 JSON 留存白板记录。当前版本没有 JSON 导入功能，重要内容请另行备份。

常用键盘快捷键

操作快捷键用途
下一条便签Enter在同一层级继续列点或记录讨论。
子级便签Tab把一个想法展开成连线分支。
返回上一级Shift + Tab书写时回到上一级继续。
便签内换行Shift + Enter在一条便签中保留较长内容。
移动选择方向键跳到附近便签或画布空白处。
连接便签Alt + C，或 Ctrl/⌘ + Enter选起点后用方向键挑目标，再按 Enter 连线或断开。
查看全部快捷键F1 或 Ctrl/⌘ + /在白板中打开完整帮助面板。

适合怎样使用

教学讲解

先写主题，随着提问展开子级，再用连线表示概念关系。课后可导出 PNG。

会议讨论

用简短便签记录决定，把理由或待办写成分支；讨论改变方向时再挪动便签。

想法发散

从一个未成形的念头开始，朝不同方向扩展相关内容，无需先选模板。

个人提纲

像写大纲一样使用 Enter 和 Tab，同时保留自由摆放和连线的空间。

存储与分享边界

ByeByeBoard 把便签、连线、样式和主题保存在当前浏览器的本地存储中。它没有账号或云同步；换浏览器或域名不会自动带走数据，清理浏览器存储也可能删除白板。

PNG 可分享画面。JSON 是导出的记录，但当前版本没有 JSON 导入功能，单靠导出 JSON 不能算已验证的恢复或迁移方案。

常见问题

需要账号吗？

不需要。打开浏览器即可使用白板。

可以用鼠标吗？

可以。鼠标能选中和拖动便签、双击新建或编辑，也能平移和缩放画布。键盘操作是推荐方式，但并非唯一方式。

能实时协作吗？

目前没有实时协作或云端分享功能。需要分享画面时可以导出 PNG。
