Practical guide

Write on a whiteboard without breaking your train of thought.

ByeByeBoard is a free-form browser whiteboard built around a continuous writing flow. Start typing to make a note, use the keyboard to expand an outline, and move around the canvas when the discussion changes direction.

Open the whiteboard →

Start a board in four steps

1. Write the first idea

Open the whiteboard and type. Your text becomes a note at the free cursor. Press Esc to finish editing.

2. Continue or branch

Press Enter to write the next note at the same level. Press Tab to add a connected child note to the right. Use Shift + Tab to continue one level up.

3. Move between ideas

Use the arrow keys to select the nearest note in a direction. From a selected note, Shift + an arrow key nudges it. You can also drag notes and pan or zoom the canvas with a mouse or trackpad.

4. Take the result with you

Download a PNG image for slides or messages, or download JSON as a record of the board. The current app does not import JSON, so keep a copy of important work separately.

Where this workflow helps

Teaching

Write a topic, add child notes as questions arise, and use connecting lines to show how concepts relate. Export a PNG after the session.

Meeting discussion

Capture decisions as short notes, branch into reasons or follow-ups, and move notes when the group revises its structure.

Early ideas

Start with an unstructured thought, then grow related notes in different directions. A fixed template is not required.

Personal outlining

Use Enter and Tab like an outline editor while still having a canvas for spatial grouping and links.

Storage and sharing boundaries

ByeByeBoard saves notes, connections, styling, and theme in the current browser's local storage. There is no account or server sync. Data in one browser or domain does not automatically appear in another; clearing browser storage can remove the saved board.

PNG is for sharing an image. JSON is an exported record, but this version has no JSON import feature. Exporting JSON alone is not a tested restore or migration path.

Common questions

Do I need an account?

No. The whiteboard runs in your browser without a sign-in.

Can I use a mouse?

Yes. You can select and drag notes, double-click to create or edit, and pan or zoom the canvas. The keyboard workflow is optional.

Can I collaborate live?

No. This version does not include live collaboration or cloud sharing. Export a PNG when you need to send a visual snapshot.
